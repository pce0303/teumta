# 혼잡도 판단 기준 초안

## 1. 문서 목적

틈타 서비스에서 여행 전 예상 혼잡도와 여행 당일 실시간 혼잡도를 판단하기 위한 초기 기준을 정의한다.

본 기준은 초기 설계안이며, 한국관광공사 관광지 집중률 예측 데이터와 SK 장소 혼잡도 데이터의 실제 응답 형식을 확인한 후 수정한다.

---

## 2. 혼잡도 데이터 구분

백엔드의 `CongestionType` 구조와 동일하게 혼잡도 데이터를 두 종류로 구분한다.

| 구분 | 의미 | 주요 활용 시점 |
|---|---|---|
| PREDICTED | 특정 미래 시각의 예상 혼잡도 | 여행 전 |
| REALTIME | 현재 측정된 실시간 혼잡도 | 여행 당일 |

---

## 3. 혼잡도 단계

백엔드의 `CongestionLevel` 구조와 동일하게 다음 네 단계를 사용한다.

| 단계 | 의미 | 사용자 안내 예시 |
|---|---|---|
| RELAXED | 여유 | 현재 비교적 여유로운 상태입니다. |
| NORMAL | 보통 | 방문객이 있지만 이용 가능한 상태입니다. |
| CROWDED | 혼잡 | 현재 혼잡하여 우회 코스를 확인할 수 있습니다. |
| VERY_CROWDED | 매우 혼잡 | 현재 매우 혼잡하여 우회 코스를 우선 추천합니다. |

각 단계의 정확한 점수 범위는 외부 혼잡도 데이터의 실제 값과 단위를 확인한 후 확정한다.

---

## 4. 여행 전 예상 혼잡도 판단

한국관광공사 관광지 집중률 예측 데이터를 사용한다.

- 사용자가 선택한 방문 예정일과 시간의 예상 혼잡도를 확인한다.
- 같은 날의 시간대별 혼잡도를 비교한다.
- 혼잡이 예상되면 상대적으로 덜 붐비는 시간대를 안내한다.
- 혼잡 상태가 지속될 것으로 예상되면 주변 로컬 연계 코스를 함께 제안한다.
- 화면에는 실시간 정보가 아니라 예상 정보임을 표시한다.

---

## 5. 여행 당일 실시간 혼잡도 판단

SK 장소 혼잡도 데이터를 사용한다.

- 현재 관광지의 실시간 혼잡 상태를 확인한다.
- CROWDED 또는 VERY_CROWDED이면 우회 코스를 노출한다.
- 혼잡도 데이터의 마지막 측정 시각을 함께 제공한다.
- 실시간 데이터 조회에 실패한 경우 예상 혼잡도를 대체 정보로 사용할지 여부는 백엔드 구현 방식과 데이터 제공 범위를 확인한 후 결정한다.
- 예상 혼잡도를 대체 정보로 사용할 경우 실시간 정보가 아님을 사용자에게 표시한다.

---

## 6. 우회 코스 추천 조건

우회 코스는 요청마다 새로 생성하지 않고, 관리자가 미리 등록한 Route 중 사용자의 남은 시간과 현재 혼잡 상태에 맞는 코스를 선택한다.

코스의 장소 구성과 방문 순서는 미리 저장하지만, 실제 이동시간과 예상 복귀 시각은 요청 시 TMAP 데이터를 이용해 다시 계산한다.

Route에 저장된 예상 이동시간과 거리는 코스 후보를 1차로 선별하는 데 사용하며, 사용자에게 제공할 최종 총 소요시간과 복귀 시각은 요청 시 TMAP 데이터로 다시 계산한다.

다음 조건을 모두 만족하는 코스만 추천한다.

1. 현재 관광지의 혼잡 단계가 CROWDED 또는 VERY_CROWDED이다.
2. 사용자에게 우회 코스를 이용할 수 있는 시간이 남아 있다.
3. 해당 Route에 포함된 로컬 장소가 모두 현재 이용 가능한 상태이다.
4. 이동시간과 권장 체류시간을 포함해 원래 관광지로 복귀할 수 있다.
5. 복귀 예정 시점의 예상 혼잡도가 현재보다 낮다.
6. TMAP을 통한 이동시간과 복귀시간 계산이 가능하다.

---

## 7. 코스 시간 구분

| 코스 구분 | 사용자 선택 시간 |
|---|---|
| 짧은 코스 | 30분 |
| 기본 코스 | 60분 |
| 여유 코스 | 90분 |

코스 총 소요시간에는 다음 항목을 포함한다.

- 관광지에서 첫 번째 로컬 장소까지의 이동시간
- 각 로컬 장소의 권장 체류시간
- 로컬 장소 사이의 이동시간
- 마지막 로컬 장소에서 원래 관광지까지의 복귀시간

코스 총 소요시간이 사용자가 선택한 시간 이하인 경우에만 추천한다.

---

## 8. 예외 처리

- 혼잡도 데이터를 조회하지 못한 경우 임의로 혼잡 단계를 생성하지 않는다.
- 현재 휴무인 장소는 추천에서 제외한다.
- 운영시간을 확인할 수 없는 장소는 추천 여부를 별도로 검토한다.
- 제한시간 안에 복귀할 수 없는 코스는 추천에서 제외한다.
- TMAP 경로 계산에 실패한 코스는 사용자에게 노출하지 않는다.
- 이용 가능한 대안 장소가 없으면 우회 코스를 제공할 수 없다고 안내한다.

---

## 9. 추후 확인 사항

- 관광지 집중률 예측 데이터의 실제 값과 단위
- SK 장소 혼잡도 데이터의 단계와 점수 범위
- 실시간 혼잡도 데이터의 갱신 주기
- 관광지마다 서로 다른 혼잡 기준이 필요한지 여부
- CROWDED 단계부터 우회 코스를 노출하는 것이 적절한지 여부
- 예상 혼잡도와 실시간 혼잡도가 다를 때의 우선순위
